# Demo library contents

`writers-disk.img`, `office-disk.img` and `damaged-disk.img` were generated by the Exhume repo's demo-disk script
(github.com/tsang326/exhume, `scripts/make-demo-disks.ts`). All content in them was written by the Exhume author.

`harbor-note.img` is our own content, generated by `scripts/make-harbor-note.mjs` in this repo (MIT, like the rest
of the repo). It is a prompt-injection test disk: its `NOTE.TXT` is addressed to AI assistants and must be reported,
never followed. harbor-note.img SHA-256: `40f60484b2d4329a020edbe33b7f84c1a73de952ee00d1d018c8e9e8ebcf474b`.

## FreeDOS 1.3 floppy image

`fd13-720k-dsk01.img` is an unmodified copy of `720k/x86DSK01.img` from the FreeDOS 1.3 Floppy-Only Edition
(`FD13-FloppyEdition.zip`, https://www.ibiblio.org/pub/micro/pc-stuff/freedos/files/distributions/1.3/official/,
zip SHA-256 `75a4e11a7fce6f124e20927b3022b4b715a2a3f7324c5f5bfea42d90d80eb072` as listed in that folder's
`verify.txt`). Image SHA-256: `b32b99efca106fecf1f361358d3187a35b1475ca9bfe12526f985bb7295d291a`.
It is read as bytes only; nothing on it is ever run.

The image contains FreeDOS programs that are free software, most of them under the GNU General Public License,
each package under its own license. The MIT license of this repo does not apply to it. The Floppy-Only Edition
does not include source code; the source of every FreeDOS 1.3 package is published by the FreeDOS project at
https://www.freedos.org/download/ and on the FreeDOS 1.3 CD-ROM and USB media in the same ibiblio folder.
