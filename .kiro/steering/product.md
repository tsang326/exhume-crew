# Product: Exhume Crew

A Kiro Crew app for people with a whole box of old floppy disks. Kiroween 2026, entered for the
**Best Kiro Crew App** bonus prize (judged by the Kiro team on value/usefulness and technical innovation, among the
top 50 entries that link a separate Crew app repo). Built on Exhume (separate repo): FAT12 reading, honest
recovered/partial/lost undelete grading, WordStar → Markdown, dBase III → CSV, PCX → PNG.

## What it does
1. The user points the app at a library folder of disk images (or loads the demo library).
2. The backend catalogues every disk without any model call: a disk card per image (files, dates, formats,
   recovered/partial/lost counts, warnings).
3. Two agents do the work that needs judgement: the **undertaker** answers questions about a disk and exhumes files
   on request; the **archivist** writes a short factual finding aid for each disk.
4. The Library page shows the shelf; the Disk page shows the graveyard, previews and exhuming. The catalogue
   exports as CSV and Markdown.

## Priorities
It never breaks on a judge's disk > it is clearly useful in two minutes with the demo library > it shows what Crew
adds (app page, backend, app MCP tools, agents with roles, optional scheduled work) > feature count.
